# SWABHIMAN

SWABHIMAN connects people hiring for local jobs with skilled workers in Chhatrapati Sambhajinagar. The app supports job listings, offers, booking updates, messages, reviews and a worker verification review queue.

The active Next.js and PostgreSQL application lives in [marketplace/](marketplace/).
