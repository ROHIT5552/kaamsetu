# SWABHIMAN

SWABHIMAN connects people hiring for local jobs with skilled workers in Chhatrapati Sambhajinagar. The app supports job listings, offers, booking updates, messages, reviews and a worker verification review queue.

The application is structured into independent frontend and backend workspaces under [marketplace/](marketplace/):
- **Frontend (`marketplace/frontend`)**: Next.js App Router UI designed for Vercel deployment.
- **Backend (`marketplace/backend`)**: Next.js API & PostgreSQL database designed for Render deployment.
